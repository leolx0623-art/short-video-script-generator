# 🎬 AI 短视频脚本生成器 (Short Video Script Generator)

> 专为 60 秒内短视频打造，支持抖音、快手、B站、小红书等平台。内置 8 种爆款结构模板，一键生成完整脚本，自动适配多平台风格。

## 🚀 快速开始

### 安装

将 `short-video-script-generator` 文件夹安装为你的 AI Skill：

```bash
# 方式一：直接下载
git clone https://github.com/leolx0623-art/short-video-script-generator.git

# 方式二：作为 Skill 安装（SOLO / AI 助手）
npx skills install short-video-script-generator
```

### 使用方式

安装后，直接向 AI 助手描述你的需求即可：

```
帮我写一个短视频脚本，主题是「3个让你效率翻倍的AI工具」，发布在抖音，45秒
```

AI 会自动：
1. 收集需求（主题/类型/时长/平台）
2. 推荐最佳结构模板
3. 生成完整脚本（开场钩子 + 正文 + 结尾 CTA）
4. 提供 3 个备选标题 + 标签推荐
5. 附带分镜建议

## 💡 创作技巧

1. **前 3 秒法则**：必须有强钩子，否则完播率低
2. **节奏控制**：每句话不超过 8 个字，停顿要明显
3. **口语化**：用"你"不用"大家"，短句为主
4. **避免废话**：短视频寸秒寸金，每秒都要有价值
