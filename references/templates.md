# 爆款短视频结构模板库

涵盖8种经过验证的短视频结构，覆盖知识分享、情感共鸣、剧情反转、种草带货等场景。

---

## 1. 干货输出型（知识分享）

**适用场景**：教程、技巧、干货知识分享
**推荐时长**：30-60秒
**核心逻辑**：问题+解决方案+总结

```
【开场钩子】（0-3秒）
❌ 错误示范：很多人都有这个困扰...
✅ 正确示范：你还在XXX？学会这3招，...

【问题痛点】（3-10秒）
抛出问题/痛点，让用户有共鸣

【核心内容】（10-45秒）
按顺序讲要点，每点用数字/序号标注
- 第一点：...
- 第二点：...
- 第三点：...

【结尾总结】（45-60秒）
总结核心观点，重复金句

【CTA引导】（最后3秒）
关注/点赞/评论引导
```

---

## 2. 反转剧情型

**适用场景**：段子、剧情、意外结局
**推荐时长**：45-60秒
**核心逻辑**：铺垫+反转+意外结局

```
【开场铺垫】（0-10秒）
制造常见场景/情境，让用户有代入感

【矛盾积累】（10-40秒）
铺垫预期，让用户以为要往A发展
埋设伏笔，制造"正常"走向

【反转爆发】（40-50秒）
突然反转，打破用户预期
反转要有冲击力，越意外越好

【意外结局】（50-60秒）
留一个小彩蛋或意外，让用户想转发
```

---

## 3. 情感共鸣型

**适用场景**：情感、励志、生活感悟
**推荐时长**：30-45秒
**核心逻辑**：共鸣点+情绪放大+金句升华

```
【情绪触发】（0-10秒）
抛出让人共鸣的场景或话语
"你是不是也遇到过这种情况..."

【情绪放大】（10-30秒）
用更多细节/故事深化情绪
让用户感同身受

【金句升华】（30-40秒）
一句有哲理/戳心的话总结
这句话要能让人截图转发

【温暖收尾】（40-45秒）
给予安慰/鼓励/希望
```

---

## 4. 种草带货型

**适用场景**：好物推荐、产品测评
**推荐时长**：30-60秒
**核心逻辑**：痛点+解决方案+产品+促销

```
【痛点切入】（0-8秒）
描述用户痛点，引发共鸣
"你是不是也为XXX烦恼？"

【方案提出】（8-15秒）
提出解决方案/产品类别

【产品展示】（15-40秒）
展示产品核心卖点
配合使用场景演示

【信任背书】（35-45秒）
数据/用户评价/品牌背书

【促销引导】（45-60秒）
限时优惠、购买链接
"点击左下角..."
```

---

## 5. 悬念引流型

**适用场景**：故事连载、揭秘、知识悬念
**推荐时长**：15-30秒
**核心逻辑**：悬念开头+关键信息+留下悬念

```
【悬念开场】（0-5秒）
抛出问题或惊人事实
"这件事，我不说你永远不知道..."

【关键信息】（5-20秒）
给出部分答案，但留有悬念
点到为止，不说透

【悬念结尾】（20-30秒）
"下期告诉你..."
引发用户关注和评论
```

---

## 6. 数字罗列型

**适用场景**：清单类、技巧类内容
**推荐时长**：30-45秒
**核心逻辑**：数字+内容+总结

```
【数字开场】（0-5秒）
直接抛出数字
"学会这5点，..."

【逐条展开】（5-40秒）
每条控制在5-8秒
- 第1点：...（配合画面）
- 第2点：...
- ...

【总结收尾】（40-45秒）
强调效果，鼓励行动
```

---

## 7. 对比冲击型

**适用场景**：前后对比、效果展示
**推荐时长**：15-30秒
**核心逻辑**：问题状态+解决后+效果展示

```
【问题展示】（0-8秒）
展示问题/困境状态
用视觉对比强化冲击

【解决方案】（8-15秒）
简单介绍解决方法

【效果展示】（15-25秒）
展示解决问题后的状态
对比越强烈越好

【引导行动】（25-30秒）
"你也想XXX？"
```

---

## 8. 热点借势型

**适用场景**：热点事件、节日节点
**推荐时长**：15-45秒
**核心逻辑**：热点切入+观点输出+个人解读

```
【热点引入】（0-10秒）
简短描述热点事件
"最近XXX事件大家都知道了..."

【观点输出】（10-30秒）
给出独特、有态度的观点
不要只当复读机

【价值提供】（30-40秒）
提供额外价值（知识/分析/预测）

【互动引导】（40-45秒）
"你怎么看？评论区聊聊"
```

---

## 结构选择指南

| 内容类型 | 推荐结构 |
|----------|----------|
| 知识教程 | 干货输出型 / 数字罗列型 |
| 段子剧情 | 反转剧情型 / 悬念引流型 |
| 情感励志 | 情感共鸣型 |
| 产品推荐 | 种草带货型 / 对比冲击型 |
| 热点评论 | 热点借势型 / 悬念引流型 |
| 清单盘点 | 数字罗列型 |
